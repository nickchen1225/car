# IRON RANGE

原創瀏覽器射擊遊戲，設計成可直接部署到 GitHub Pages。

## 功能
- 原創 Canvas 射擊場
- WASD / 自訂鍵盤
- 滑鼠瞄準與射擊
- Xbox / USB Gamepad
- 敵人 AI 移動追蹤
- 彈匣與換彈
- 血量、擊殺、分數、連殺倍率
- Wave 系統
- 命中標記、受傷效果、粒子效果
- 手機簡易觸控移動
- GitHub Pages / 404 / .nojekyll

## GitHub Pages
把全部檔案放在 repository 根目錄，Settings → Pages → Deploy from a branch → main → /(root)。

## 注意
本專案為原創範例，不包含任何第三方遊戲的圖片、音效或品牌素材。
